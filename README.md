# Ahmed Hesham Nour El-Din - Portfolio

Static portfolio site (HTML/CSS/JS only, no build step).

## Files
- `index.html` - the whole site
- `Ahmed_Hesham_CV.pdf` - CV used by the "Download CV" button
- `images/` - put `work-1.jpg` ... `work-8.jpg` here

## Publish on GitHub Pages
1. Create a repository and upload all of these files (keep the `images` folder).
2. Settings > Pages > Source: "Deploy from a branch", Branch: `main`, Folder: `/ (root)`.
3. Wait 1-2 minutes; the link appears at the top of the Pages screen.
